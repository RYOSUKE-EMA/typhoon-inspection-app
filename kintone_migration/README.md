# 点検アプリ kintone完結化（Vercel廃止）移行メモ

2026-11-12 江間さん決定：**プロセス管理を使い、安全旬報から段階的に移す**。

## 方針
- Vercel（Flask + Neon）を介さず、kintoneの標準機能＋JSカスタマイズだけで動かす。
- 承認・差し戻しは kintone 標準のプロセス管理。通知もプロセス管理／条件通知の標準機能。
- 第1段階＝安全旬報。台風・災害時・足場は当面 Vercel 版のまま（app 5287 に同期）。
- 切替手順：新アプリを江間さんが試用 → OKなら既存旬報データを移行 → Vercel版トップの安全旬報カードを新アプリへのリンクに差し替え。

## 構成（第1段階）
| 用途 | アプリ | 備考 |

### 安全旬報アプリ：プロセス管理
- ステータス：未提出 → TL承認待ち → 確認済、TL承認待ち → 差し戻し → TL承認待ち
- アクション：提出する（作成者）／承認する・差し戻す（承認TLフィールドのユーザー）／再提出する（差し戻し後）（作成者）／移行データ登録（移行元IDありのみ）
- 保存時にJSで「提出する」を自動実行（保存＝提出）
- 差し戻す時、JSで理由入力（任意）→「差し戻し理由」フィールドへ
- 安全検査室：条件通知（ステータス＝TL承認待ち）

### JS（PC・スマホ両方に登録）
- 新規作成時：点検項目60行を自動展開（設定アプリの「点検項目」レコードから。無ければ内蔵の既定）、前回の工事・作業所長をプレフィル
- 詳細：PDF出力（pdf-lib＋Noto Sans JPサブセット、様式PDFに重ね書き）、工事ごと一括PDF
- 提出状況ビュー（カスタマイズビュー）：041＋追加対象、対象期間、旬ごとの未提出/提出済/承認済/差し戻し/期限超過/対象外

## ファイル
- `kapi.py`：REST APIヘルパー（ログイン認証は ~/.claude/garoon_config.json）。`app_ids.json` にアプリID
- `setup_apps.py`：アプリ・フィールド・プロセス管理・通知・一覧・権限（app5287と同じ）を設定（再実行可）
- `seed_conf.py`：設定アプリにPDF資材（フォント・様式）・点検項目60件・追加対象81042262を登録
- `junpo.js`＋`lib/`（pdf-lib 1.17.1, fontkit 1.1.1）：`deploy_js.py` でPC・スマホ両方に登録
- `assets/NotoSansJP-junpo.ttf`：Noto Sans JP を JIS第1・第2水準＋記号でサブセット（2.7MB）。pdf-libの subset:true は文字が欠けるため subset:false で埋め込む
- `migrate_records.py`：旧データ移行（再実行可・移行元IDで重複防止）。移行中だけ「未提出」の作業者を空にして「移行データ登録」を実行し、終了後に作成者へ戻す
